# Fonts for invitation QR cards

The server PNG compositor uses the same DM Serif Display / Roboto brand pairing as the application, without fetching fonts during a download. Next.js file tracing includes these fonts and the canonical Undara logo for the QR route.

Unmodified font sources from [Google Fonts](https://github.com/google/fonts):

- `DMSerifDisplay-Regular.ttf`: `ofl/dmserifdisplay/DMSerifDisplay-Regular.ttf`, Git blob `bc5ed0cea657f264ea9c2a11a54da62ed619c5da`; license `DMSerifDisplay-OFL.txt`.
- `Roboto.ttf`: `ofl/roboto/Roboto[wdth,wght].ttf`, Git blob `5522a368d9072fd88c299916e61fcff369949061`; license `Roboto-OFL.txt`.

The included SIL Open Font Licenses and copyright notices apply to the fonts. The canonical logo remains at `public/assets/brand/undara/logo.webp`; do not replace it with typed lettering.
